# Possible next releases

These are candidate improvements, not features included in v1.0.0 and not scheduled work.

## v1.1 — Editing marks

Select, move, duplicate, resize, and delete individual strokes and shapes; add a whole-stroke eraser; improve keyboard editing and object inspection. Preserve the existing JSON format through an explicit migration.

## v1.2 — A small sketchbook

Multiple named pages, local project thumbnails, explicit restore points, and optional undo-history persistence. Keep JSON files portable and browser storage failures visible.

## v1.3 — Trace and compose

Local raster-image import with size limits, a movable reference-image layer, layer visibility/locking, and clear export rules for SVG files containing raster imagery.

## v2.0 — More expressive ink

Additional tested brush types, rotation, lasso selection, optional stroke replay, and further export formats where their encoders can be bundled and verified offline.

## Verification priorities

Before expanding the toolset, test physical iPhone/iPad Safari, Android Chrome, real stylus pressure, large canvases on lower-memory devices, native file saving/sharing, and service-worker updates at an actual HTTPS subdirectory deployment.
